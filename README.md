# 网络音频权利与多形态分发账本

管理网络音频素材授权、多形态版本、发布门禁和收入结算。

## 参与方与事实

主要参与方包括音频创作者、节目编辑、嘉宾及权利人、法务人员、商务人员、平台运营人员。领域资料记录以下已经确认的事实：

- 网络音频覆盖有声书、广播剧、播客和视频播客等多种内容形态
- 行业正在形成一次录制、多形态分发的生产方式
- AI 配音、声音克隆、版权归属和合成内容标识带来新的治理需求

## 业务约束

- 素材授权范围
- 成品版本水位
- 合成内容标识
- 收入分成
- 撤回与下架
- 商业秘密裁剪
- 发布门禁先审后发
- 退款撤单与后补版权费冲正落账
- 签署授权与许可解释职责分离
- 角色信息按需裁剪

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/audio_context.py` 负责读取和校验这些资料。

## 服务核心

`src/` 下是领域核心的纯 Python 实现，只依赖标准库：

- `assets.py` 内容资产谱系：从选题立项起登记参与者、素材来源与人工或合成片段
- `rights.py` 权利许可：许可与同意登记、法务解释回避、统一撤回入口与覆盖判断
- `versions.py` 成品版本：冻结引用片段与权利水位，冻结后不可更改
- `gate.py` 发布门禁：先审后发，授权失效停在补审，片段变更时列出受影响形态
- `ledger.py` 收入结算账本：按合同归集、冲正落账、回执幂等、关账可续做
- `service.py` 服务门面，串联以上模块
- `views.py` 角色视图裁剪与权利人许可核对

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
