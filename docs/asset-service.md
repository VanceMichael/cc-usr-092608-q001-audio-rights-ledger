# 网络音频内容资产服务设计

面向机构负责人的建设目标：从选题立项起完整记录内容资产与权利信息，支持一次录制、多形态分发，并保证权利、发布、结算三条线各自可追溯。本文档只描述领域模型与不变式，不涉及具体技术选型。

## 生命周期

1. **选题立项**：建立项目，记录参与者（创作者、嘉宾、配音、编辑）及其角色，登记原始录制、文字稿和素材来源。
2. **权利归集**：为每个参与者登记声音与肖像同意，为每段配乐登记音乐许可。同意与许可都带用途、地域、期限三维范围；AI 配音所用声音样本须登记来源与对应同意。
3. **制作**：成品由片段组成，片段分人工与合成两类，合成片段必须带合成内容标识；每个片段记录引用的素材、同意和许可，得出该片段的可用范围。
4. **版本冻结**：每个成品版本（完整音频、视频播客、付费专辑、跨平台切片）定稿时冻结所引用素材与权利水位的快照，冻结后不可改，修改只能产生新版本。
5. **发布门禁**：分发计划按渠道逐条校验权利水位（用途、地域、期限在发布截止时均有效）。任一授权过期或缺失，该计划停在补审阶段，不得先上线再补手续。
6. **分发与下架**：记录每个版本在各渠道的上架、下架及原因。
7. **收入与结算**：广告分成、会员收入、IP 授权、线下活动收入按各自合同归集入账；退款、撤单、后补版权费以冲正方式落账；月末关账。
8. **撤回与追溯**：嘉宾或权利人撤回授权仅面向未来；系统评估影响并触发重审、下架或补授权，此前合法发布的责任记录完整保留。

## 核心实体

| 实体 | 关键内容 |
| --- | --- |
| 项目 Project | 选题、参与者及角色、状态 |
| 录制 Recording / 文字稿 Transcript | 原始素材与其来源、归属 |
| 素材 Asset | 来源、授权链、引用它的片段 |
| 同意 Consent | 声音/肖像，用途范围，可撤回（仅未来生效） |
| 许可 License | 音乐等第三方权利：用途、地域、期限、被许可人 |
| 片段 Segment | 人工或合成、合成标识、引用素材与权利、可用范围 |
| 成品版本 Version | 形态、冻结的素材与权利水位快照、父版本 |
| 分发计划 DistributionPlan | 渠道、地域、计划时间、状态机 |
| 合同 Contract / 流水 LedgerEntry | 收入归集规则；正账与冲正，只增不改 |
| 分账 Settlement | 按合同与结算期计算，幂等键标识 |
| 事件 Event | 全部责任记录（授权、发布、撤回、处置），只增不改 |

## 不变式

- **版本冻结**：版本一旦冻结，其引用的素材与权利水位快照不可变；任何修改生成新版本并指回父版本。
- **影响可追溯**：修改一处片段时，影响清单 = 引用该片段的冻结版本 × 各版本已发布形态，逐项给出重审、下架或补授权的处置。
- **发布门禁**：分发计划只有在全部引用权利于发布截止时有效，才能进入可发状态；授权过期一律停在补审阶段。
- **账本只增不改**：收入、退款、撤单、后补版权费均为独立流水，更正一律用冲正，不修改历史条目。
- **分账幂等**：分账以（合同、结算期、平台回执号）为幂等键；平台重发回执或月末关账中断后续做，不产生重复付款。
- **撤回不抹历史**：撤回仅取消未来使用；此前合法发布的记录、分账与责任事件保留，供核对与审计。
- **角色信息隔离**：创作者、编辑、法务、商务、平台运营只见职责内信息；商业秘密按角色裁剪。
- **许可解释专责**：签署授权的人不代替法务解释许可；许可条款的解释与变更结论只能由法务登记。

## 角色与可见性

| 角色 | 可见/可操作 | 不可见 |
| --- | --- | --- |
| 创作者 | 自己参与的片段、成品版本、自己应得分成 | 他人合同与报价 |
| 节目编辑 | 项目内素材、片段、版本与发布状态 | 合同金额明细 |
| 法务人员 | 全部同意、许可、撤回与责任记录；登记许可解释 | 经营数据 |
| 商务运营 | 合同、收入流水、分账与未结款项 | 同意书原件中的敏感身份信息 |
| 平台运营 | 任一版本的可用渠道、下架原因、未结款项、权利风险 | 与渠道运营无关的合同条款 |
| 嘉宾及权利人 | 自己的许可被哪些内容使用、对应结算 | 其他参与方信息 |

## 开放问题

- 声音样本的撤回入口尚未统一，需要约定跨平台撤回通知的格式与时限。
- 跨平台切片在第三方平台被二次搬运时，下架与追责流程待定义。
- 付费专辑退款跨结算期时，冲正与已分账金额的追回顺序待与财务确认。
