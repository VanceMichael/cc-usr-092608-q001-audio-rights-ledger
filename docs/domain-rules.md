# 领域边界

管理网络音频素材授权、多形态版本、发布门禁和收入结算。

现有领域资料围绕以下边界组织：

- 内容资产谱系
- 权利许可版本
- 多形态发布门禁
- 收入结算账本
- 到期与撤回任务

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 领域不变量

代码中的服务核心必须始终满足以下规则：

- 资产谱系只增不改：参与者、项目、素材、片段登记后不可篡改，合成片段必须携带合成内容标识。
- 许可限定用途、渠道、地域与期限；声音与肖像同意只能由当事人本人签发，素材许可只能由素材权利人签发。
- 许可解释只能由法务出具，签署该许可的人应当回避，不能代替法务解释许可。
- 撤回走统一入口，只影响生效之后的未来使用；撤回不删除任何历史记录，此前合法发布的责任记录保留。
- 成品版本冻结所引用的片段与权利水位，冻结结果不可更改；修改内容只能产生新版本或触发影响分析。
- 片段变更时必须能列出需要重审、下架或补授权的全部已发布形态；下架保留下架原因与发布历史。
- 发布门禁先审后发：授权在发布截止前过期的计划必须停在补审阶段，不能先上线再补手续。
- 收入按广告分成、会员收入、IP 授权、线下活动四类合同归集；退款、撤单与后补版权费一律冲正落账，原账目不修改。
- 平台结算回执按回执号去重，重发不重复入账；月末关账按合同应付未付额分账，中断后可安全续做且不重复付款。
- 角色视图按需裁剪：创作者与编辑不看合同金额，商务不看片段内容，法务不看收入分成，平台运营可见渠道、下架原因、未结款项与权利风险；权利人可核对自己的许可去向。
